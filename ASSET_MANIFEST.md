## Milestone 11.3 — Production Optimized Derivatives

These derivatives were created non-destructively for controlled-demo performance. They do not replace the original supplied artwork as source material, and they do not change any visual/content approval status. All derivatives remain `NEEDS CLEANUP` when their source contains provisional/generated marks or embedded text.

### Optimization Method

| Tooling | Result |
| --- | --- |
| WebP / AVIF | No local encoder available. `sips` could not write WebP on this machine. |
| Production derivative format | Conservative high-quality JPEG derivatives via macOS `sips`. |
| Source preservation | Original PNG assets remain untouched. |
